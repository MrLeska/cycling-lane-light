# cycling-lane-light
My Project is a bike awareness sensor and light. Its mountable onto the seat stem behind the rider and features 3 LED lights, a regular red rear facing light to alert others that will grow brighter when slowing down or breaking, and two parallel side LED displays that will project onto the road, creating a visible lane around the bike, that will also switch from white to red when breaking. This is meant to be primarily used for road cyclists in places with out proper biking infustrcture. 
---------------------------------------------------------------------------------------------------------------------------------
I made this because I am currently training for an Ironman, and during many of my long rides I have found that bike lanes abruptly end or proper lighting isn't available. I hope that by creating this device I will be able to improve safety whilst not taking away from the aesthetics of a bike by mounting large adhesive reflective pads that are frankly ineffective.
